# PATCH - Auth

## `PATCH /api/v1/auth/change-password`
- **Policy:** `[Authorize]`
- **Trạng thái:** `CÓ SẴN`
- **Dùng chung với:** Tất cả roles đã xác thực
- **Ghi chú:** Đổi mật khẩu (yêu cầu mật khẩu cũ và mật khẩu mới).
